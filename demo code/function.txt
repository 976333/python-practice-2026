# # 3. What does `sorted()` do?

# Python's:

# ```python
# sorted()
# ```

# takes a collection and returns a **new sorted list**.

# For example:

# ```python
# numbers = [30, 10, 20]

# result = sorted(numbers)
# ```

# Result:

# ```text
# [10, 20, 30]

# # 4. What is `key=`?

# ```python
# key=lambda player: player.jersey_number
# ```

# > **Use this value to decide the sorting order.**

# For your code:

# ```python
# key = player.jersey_number
# ```

# means:

# > Sort players according to their jersey number.

# ---

# # 5. Now the Lambda Function

# Your lambda is:

# ```python
# lambda player: player.jersey_number
# ```

# A lambda is simply a **small anonymous function**.

# The same thing can be written using a normal function:

# ```python
# def get_jersey_number(player):
#     return player.jersey_number
# ```

# Then:

# ```python
# sorted_players = sorted(
#     self.players,
#     key=get_jersey_number
# )
# ```

# So these two are equivalent:

# ### Lambda version

# ```python
# key=lambda player: player.jersey_number
# ```

# ### Normal function version

# ```python
# def get_jersey_number(player):
#     return player.jersey_number

# key=get_jersey_number
# ```

# The lambda is just a shorter way.

# ---

# # 6. Understand the lambda syntax

# ```python
# lambda player: player.jersey_number
# ```

# Think of it as:

# ```text
# lambda     player       :       player.jersey_number
#   ↑           ↑                   ↑
# keyword    parameter            return value
# ```

# ### `lambda`

# Tells Python:

# > I'm creating a small anonymous function.

# ### `player`

# This is the **parameter**.

# It represents one player object at a time.

# ### `:`

# Separates the parameter from the expression to return.

# ### `player.jersey_number`

# This is the value returned by the lambda.

# ---

# # 7. How does `sorted()` actually use it?

# Suppose your players are:

# ```text
# Player A → jersey 45
# Player B → jersey 7
# Player C → jersey 18
# ```

# Python effectively does:

# ```text
# player A → lambda → 45
# player B → lambda → 7
# player C → lambda → 18
# ```

# So `sorted()` sees:

# ```text
# 45
# 7
# 18
# ```

# Then it sorts those values:

# ```text
# 7
# 18
# 45
# ```

# Therefore the players become:

# ```text
# Player B → 7
# Player C → 18
# Player A → 45
# ```

# ### Important:

# The lambda **does not sort anything itself**.

# The lambda only tells `sorted()`:

# > "For each player, use their jersey number as the sorting value."

# ---

# # 8. Why not simply write this?

# You might wonder:

# ```python
# sorted(self.players)
# ```

# Why don't we do that?

# Because Python doesn't automatically know how to compare your `Player` objects.

# For example:

# ```text
# Player object > Player object
# ```

# Python doesn't know whether you want to compare:

# - name
# - jersey number
# - age
# - role
# - batting style

# So we explicitly tell it:

# ```python
# key=lambda player: player.jersey_number
# ```
